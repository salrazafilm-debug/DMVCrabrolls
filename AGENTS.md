# DMV Crabrolls editing standard

- Keep edits scoped to the user's requested sections. Preserve unrelated content, photo assignments, layout, and interactions.
- Discussion and planning do not authorize implementation of the pending menu, copy, flag, heading, or banner changes. Implement them only after the user asks to proceed.
- Before publishing, review the complete page: hero, menu, owner, team, location, catering, gallery, footer, and dialogs. Check desktop and mobile layouts visually when supported browser tooling is available; check navigation, buttons, forms, assets, JavaScript, overflow, and section boundaries.
- Correct regressions introduced by an edit before delivery. Prefer section-scoped styles and isolated interaction code.
- If browser verification is unavailable, report that limitation explicitly; do not claim the website's visual appearance or interactions were browser-tested. Perform available source and asset checks and preserve unrelated sections.
